# opening-storyboard-24s

来源：对话消息 83（assistant）。

状态：助手建议，24秒完整版与6–8秒循环未定稿。

---

如果这段动画要完整包含你描述的叙事，28秒略长，但压到十几秒也会让角色互动和世界揭示变得仓促。

我的建议是：

- 首次进入游戏：22–24秒完整版。
- 后续普通加载：6–8秒精简循环版。
- Logo最迟在第20–22秒出现，之后进入可循环等待状态。

因为你设计的内容，本质上已经接近“微型开场动画”，不只是普通加载动效。

## 推荐的24秒版本

| 时间 | 内容 |
|---|---|
| 00–03s | 跟随甲虫低空飞行 |
| 03–05s | 甲虫落叶，米露卡探头平视 |
| 05–08s | 切到侧面，米露卡蹲着并被声音吸引 |
| 08–12s | 四人侧面赶路、打闹和反应 |
| 12–15s | 米露卡起身追赶，五人进入洞穴 |
| 15–17s | 洞穴黑暗转场 |
| 17–22s | 五人走出悬崖洞口，镜头升高揭示新世界 |
| 22–24s | Logo浮现，进入等待状态 |

这个长度能够保留：

- 甲虫与米露卡的情感瞬间；
- 四人之间的性格互动；
- 米露卡掉队并追赶的故事逻辑；
- 洞穴转场；
- 最重要的新世界大远景。

## 为什么不建议只有6–10秒

6–10秒只适合完成其中一个段落，例如：

> 甲虫飞行 → 米露卡探头 → Logo。

如果硬塞入五人打闹、进洞和世界揭示，结果会像快速播放的预告片，角色动作没有起承转合，观众甚至来不及辨认五个人。

## 为什么不建议固定28秒以上

如果玩家每次加载都被迫观看28秒，重复几次后会明显烦躁。尤其实际加载只需要5秒时，动画反而会成为阻塞。

因此最好采用双版本：

### 首次加载完整版：24秒

完整展示世界观，可以允许跳过，但第一次最好默认播放。

### 普通加载循环版：6–8秒

从完整版中提取：

- 甲虫落在叶片上；
- 米露卡眨眼观察；
- 或五人背对镜头看云海；
- 云层、头发和披风缓慢运动；
- Logo与加载进度持续显示。

结论：你的完整故事最合适做成约24秒，而不是6秒；6秒应该只是其中一个生成节点，或者后续普通加载使用的循环版。
