## 游戏类型

```text
网页横屏奇幻动作冒险游戏《星谱大陆》，玩法参考《元气骑士》。当前探索角色选择页面的UI美术，搭配有丰富光影和体积感的奇幻角色美宣。

重点参考垫图的多彩色块搭配、饱满粗字、紧凑层级和活泼的游戏感。采用简洁有厚度的轮廓、短投影、局部高光和少量网点纹理，形状略带不对称与动势。

配色丰富，按功能分工：深靛蓝作为共同承托色，蓝紫用于普通组件，明黄色用于确认主按钮，青绿用于选中标记，珊瑚橙和玫红作为少量局部重音，文字以白色或深靛蓝保证清晰。允许鲜明冷暖对比，不再把整套UI统一染成蓝紫色。

每个组件以一种主色搭配一种承托色为主，明亮颜色集中于主操作和选中状态。色彩鲜活但不依赖发光；避免荧光描边、闪电尖刺、厚重金属、膨胀的软糖质感。

只借鉴垫图的视觉语言，不复制春节装饰、通行证、奖励系统和原有页面布局。
```

## 必要控件

```text
生成一张多彩奇幻游戏UI组件展示板，重点制作：

1. 确认选择按钮
明黄色主体、深靛蓝粗字和短距离压底，圆润但有轻微前进动势，局部用珊瑚橙表现厚度。展示默认与按下状态，文字均为“确认选择”；按下时位置略下沉、投影缩短，不改变基本轮廓。

2. 返回、左右切换、关闭、设置
使用统一的蓝紫或深靛蓝承托与白色符号，造型紧凑清楚，局部允许少量彩色细节。次要按钮的亮度与装饰明显少于主按钮。

3. 两张竖向角色卡框
普通态采用蓝紫框体与深靛蓝名字底板；选中态保留同一结构，以明黄色边缘和小型青绿勾选标记突出。肖像区充分留空，不生成角色或人物剪影，不用光雾围住卡片。

4. 角色名字与介绍文字样式
名字使用饱满、有节奏的白色粗字和简短深色投影，可配一个小型彩色标签。介绍文字简洁易读，不包进巨大信息面板。

5. 三个小型信息图标底座
分别以青蓝、珊瑚橙、紫色表现色彩变化，统一轮廓、厚度与符号风格，只放简单示意符号。

6. 加载进度条
深靛蓝细长轨道、青蓝填充和一个小型明黄色进度端点，边框简洁，无外围粒子。

主按钮与角色卡作为展示重点，其余组件紧凑排列。统一边框与投影语言，通过色块分配体现丰富感，不给每个组件叠加彩虹渐变。

纯浅灰背景，组件彼此分开、留足间距。只展示独立组件，不绘制人物、场景、完整页面或额外玩法系统。
```
