## 2. 已确认的大厅背景方向

### 场景与镜头

- 16:9 横屏，明亮白天的悬崖营地，远景是云海、层叠山峰和浮空岛。
- 不使用发光蜿蜒道路；不在晴朗白天点旺盛篝火。旅行木箱、帐篷、地图、卷毯和未点亮的灯笼可以保留为营地信息。
- 使用贴近地面的广角大透视：近景营地物件略放大并切出画面，中景人物，远景浮岛明显缩小。
- 背景采用约 8–10 度的轻度荷兰角形成对角线空间；程序叠加的 UI 必须保持水平。
- 后续动画镜头固定，不继续旋转、摇晃或大幅推拉。

### 五人状态与空间

- 五人分散在前景、中景和远景，不围成一团，不排队，不形成面向镜头的合影。
- 目标朝向比例为：两名四分之三正侧面、两名侧面、一名背面。人物看队友、地图、小生物或远方，没有人直视镜头。
- 米露卡必须落地。扫帚只是需要时召唤的魔法工具，营地待机中不持续骑乘，也不默认展示其他魔法工具。
- 佩可采用自然站姿，左右两条腿结构完整、双脚落地，腿部不得与背包、岩石或身体粘连。
- 人物之间保留清楚空隙，身体互不遮挡；人物集中在画面中部，左右 UI 区域保持相对简洁。

### 让画面鲜活的轻事件

- 金发紫衣白裤女性展开地图并指向远处浮岛，承担“规划下一段旅程”的主叙事。
- 一只圆润的绿色小生物在佩可的背包附近偷偷探头，佩可低头发现它，形成轻喜剧副叙事。

- 趣味来自角色之间的视线和反应，不依赖所有人物看镜头，也不增加战斗、爆炸或大动作。
