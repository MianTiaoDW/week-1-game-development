## 三、角色选择页：已确认结构

- 核心概念：**全屏角色出场动画之上的沉浸式角色选择 UI**。
- 不抠人物、不换成统一站姿、不新造背景；角色美宣的完整人物、构图、光影和场景必须保留。
- 左上返回；左侧角色名、身份、介绍和三个特性；左右中部切换箭头；右上金币与宝石；底部五张角色卡；右下 `CONFIRM`。
- 五卡当前显示顺序：`MILUKA → NAISHA → PEKO → YANQIU → BOMU`。注意：当前 UI 图片一直写 `NAISHA`，而角色历史文档常写 `NYSHA`；英文拼写尚未由用户最终核验，不得静默改写。
- 金币示例 `12,580`，宝石示例 `680`。
- 不使用职业／武器／定位小图标，不做卡片底部尖角。
- 1920×1080 基准安全区：左右至少 96 px，上下至少 54 px。
- 当前按钮只写 `CONFIRM`，不写 `SELECT MILUKA`。

## 四、最新视觉判断

此前的大面积白色／奶油色板块已被用户指出“差点意思”：它会把沉浸式奇幻冒险页拉向儿童益智或休闲手游，也遮断背景空间。随后尝试的深蓝星谱玻璃又过于单色、平、缺少功能层级。

最新方向来自用户提供的老师案例，但只借它的 UI 工艺，不复制兔子、魔术文字、图标、紫色背景或版式：

- 清新、可爱、圆润，但仍保持精致奇幻冒险感。
- 不同功能组件使用不同强调色，不能全页一套蓝色或紫色。
- 所有按钮属于同一套圆润 2.5D 家族：顶部高光、中部干净渐变、较深较厚的底沿、清楚但不尖锐的深色内描边、短而柔和的右下投影；一眼看出可按压厚度。
- 返回按钮：薰衣草蓝／蓝紫；左右箭头：天蓝／青蓝＋象牙白。
- 货币条：深靛蓝底；金币配金黄图标与橙色加号，宝石配青蓝晶体与绿色加号。
- 三个特性胶囊分别用青绿、天空蓝、嫩黄绿，不再全部同色。
- `CONFIRM` 是唯一一级操作：芒果黄／金黄色渐变、橙金厚底沿、深靛蓝文字，不能继续做蓝色按钮。
- 五张角色卡同一结构、不同角色强调色：米露卡青绿＋金，奈纱冷蓝＋紫，佩可珊瑚橙＋黄，砚秋薰衣草紫＋金，波姆天蓝＋薄荷绿。
- 米露卡选中态只比其他卡放大约 5%、上移约 6 px，加青绿描边和一颗小金色四角星；不要巨大光环。
- 组件应有层级，但不能变成厚重金属 RPG 框、尖锐竞技 HUD 或复杂珠宝首饰。

把米露卡完整角色选择页候选作为图 1，把老师的清新圆润案例作为图 2。图 2 只作 UI 工艺参考；若生成平台只允许一张参考图，优先图 1，并把下列工艺写进文字。

```text

页面结构保持：左上返回；左侧 MILUKA、ASTRAL APPRENTICE、Always chasing the next falling star.，以及 CURIOUS / STAR MAGIC / AGILE；左右中部切换箭头；右上金币 12,580 与宝石 680；底部五张 3:4 角色卡，顺序 MILUKA、NAISHA、PEKO、YANQIU、BOMU；右下按钮只写 CONFIRM。不要职业或武器小图标，不要卡片底部尖角。

整套 UI 做成统一的清新圆润 2.5D 奇幻冒险按钮家族：每个组件都有顶部柔亮高光、干净的中部渐变、较深较厚的底沿、清楚但圆钝的深色内描边、短而柔和的右下投影，形成明确可按压厚度和前后层级。不同功能使用不同颜色，但形状、描边、光泽与阴影工艺统一。

返回按钮用薰衣草蓝到蓝紫；左右箭头用天空蓝／青蓝和象牙白；金币条用深靛蓝底、金黄图标、橙色加号；宝石条用深靛蓝底、青蓝晶体、绿色加号。三个特性胶囊分别用青绿、天空蓝、嫩黄绿。右下 CONFIRM 是唯一一级按钮：芒果黄到金黄色渐变、橙金色厚底沿、深靛蓝文字，体积与对比最强，绝不能做成蓝色。

禁止：整页同一种蓝色或紫色，平面玻璃胶囊，大面积白色／奶油色面板，所有按钮同色，蓝色 CONFIRM，普通企业 UI，尖锐竞技 HUD，厚重金属 RPG 框，复杂珠宝装饰，过多粒子与外发光，职业图标，复制图2角色和资产，额外文字，错拼，水印，设备样机。
```

### 本轮验收只看五件事

1. `CONFIRM` 是否明显是暖黄色一级按钮。
2. 返回、箭头、货币、特性、角色卡是否颜色分工明确但仍像同一家族。
3. 每个按钮是否有可感知的厚度、底沿和短投影，而不是平面玻璃片。
4. 米露卡美宣是否仍是第一视觉中心，没有被大面板切断。
5. 五张角色卡是否既统一又能靠强调色区分角色。

如果这轮仍然“正确但普通”，立即停止整页叠加提示词，回到 `docs/HANDOFF_2026-08-27_CHARACTER_SELECT_UI.md` 的独立 UI 资产板方案；不要连续三轮修同一张全页图。

## 七、Logo 对话最新停点

名称已锁定：中文《星谱大陆》，英文 `ASTRAL SCORE`。

Logo 性格：圆润、厚实、饱满、亲和但不幼稚；整体向前／向右上运动；中英文均为单行；星谱、谱线、跑道或轨迹只做克制细节。不要暗黑、锐利、战斗化、哥特或金属武器感。

执行顺序：

1. 先只生成中文。图 1 只放用户最喜欢的 `DRONERS` 类圆润字标参考；不混入角色、美宣或其他 Logo。
2. 中文精确写 `星谱大陆`，必须单行；“星谱”为主体，“大陆”约为其高度 80%，仍处于同一行。天蓝／青蓝／白色渐变，深海军蓝厚描边，冷蓝错位投影；“星”负责启动动势，“谱”的局部笔画可延伸成克制的星谱轨迹。
3. 一次出 4 个，只按轮廓、字势和向右上动感选型，不要求 AI 一步写对全部汉字。
4. 中文选中后，用该候选作图 1、`DRONERS` 参考作图 2，再生成单行 `ASTRAL SCORE`。`ASTRAL` 高度约为 `SCORE` 的 85%–90%；可在 `O` 中放一个小星核，标题下或中部只留一条克制轨迹线。
5. 最终在 Photoshop／Illustrator 中校字与描摹。AI 文本错误不等于方向失败，但不得直接将错字图定稿。

Logo 禁止项：错字、额外文字、副标题、换行、角色、场景、城堡、盾牌、皇冠、武器、龙、密集音符、哥特体、红黑主色、尖锐金属、书法、幼儿泡泡字、彩虹霓虹、镀铬、复杂浮雕、临摹、水印和样机。

## 八、加载页动画对话最新停点

视觉核心仍是：**英雄式卡通奇幻美宣的角色塑造＋风格化 3D 电影 CG 镜头**。不要真人写实，也不要把平面插画简单推拉。

三段结构：

1. 甲虫段约 6–7 秒：低机位跟随草丛，甲虫落到叶片，叶片下压回弹，米露卡从低于视平线的位置探头。
2. 小队段约 7–8 秒：镜头顺米露卡视线找到队友；佩可倒退逗奈纱，奈纱推她向前，砚秋无奈看着，波姆大笑，米露卡追上。
3. 世界段约 5 秒：悬崖揭示大世界，前景草叶与甲虫重新出现，回到循环入口。

三张静帧是运动锚点，不是三张海报。每张都要明确方向、景深和镜头连接。首段动作过载时，把“米露卡转头＋镜头摇向队伍”放在第一段末尾的极短过渡，或让第二段开头已经面向队伍。

准确未完成项：星荚甲虫物种方向已接近通过，但最后局部微修仍要做到主要背对镜头、严格两根嫩芽触角、六条腿、窄折叠翅膜。通过后才能锁定甲虫、制作米露卡平视探头终帧并进行第一段视频测试；随后才进入群像和悬崖帧。禁止恢复全图 Banana 精修。
